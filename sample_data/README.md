# 阶段 0 测试数据说明

这些数据仅用于开发和自动化测试，不代表真实政务数据。

涉及更新滞后和固定风险数量的回归结果统一使用评估基准日期 `2026-07-17`。

| 文件 | 特征 | 后续预期 |
| --- | --- | --- |
| `good_dataset.csv` | 日期、数值、来源、版本等字段相对完整。 | 13 项指标均可计算，其中格式异常、重复和 IQR 异常值比例为 0。 |
| `good_dataset.xls` / `good_dataset.xlsx` | 与 CSV 内容一致，用于验证新旧 Excel 格式及工作表选择。 | 13 项指标均可计算，工作表名称保留为“服务事项”。 |
| `bad_dataset.csv` | 存在缺失、重复、日期、URL 和数值格式混杂。 | 缺失、重复、格式异常、时间信息不足和可溯性覆盖不足指标应被触发；IQR 指标应明确显示无法评估。 |
| `format_messy_dataset.csv` | 字段完整且无重复，但日期、URL 和数值格式混杂。 | 触发格式与类型风险，不应触发缺失、空白或重复风险。 |
| `minimal_dataset.json` | 只有基础文本字段，未提供时间、来源、版本或数值字段。 | 格式、时间、来源、版本和 IQR 相关指标应显示“无法评估”，而不是输出 0。 |
| `nested_dataset.json` | 包含嵌套对象的 JSON。 | 不擅自展平，网页应返回可解释且可下载的失败报告。 |
| `geojson_feature_collection.geojson` | 两条 Feature，包含扁平属性、点和线几何。 | 每条 Feature 映射一行；保留 properties、Feature ID 和空间摘要；原始坐标不展开。 |
